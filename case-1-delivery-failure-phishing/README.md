# Case 1: Delivery Failure Phishing Attack

A suspicious email was reported that appeared to be a delivery failure notification. The objective of this analysis is to investigate the email, extract useful artifacts, and determine whether it is malicious.

---

## Email Description:

This email looks like an automated delivery failure message, saying that the email could not be delivered to the recipient. It also mentions that the message was generated by mail delivery software and includes details about the failed delivery.

However, emails like this are often used in phishing attacks to make the message appear legitimate and trick users into opening attachments or interacting with malicious content.

## Analysis:

### Attachment Analysis:

The attachment contains another `.eml` file, which includes a suspicious URL. In this case, the attachment was opened to extract the embedded URL.

In a real-world scenario, attachments should not be opened directly. The file should first be analyzed safely by generating its hash (such as SHA256) and checking its reputation using tools like VirusTotal or Talos File Reputation to determine if it is malicious or safe.

---

### URL Analysis:

The extracted URL was analyzed using VirusTotal and URL2PNG.

VirusTotal Report: [View Analysis](https://www.virustotal.com/gui/url/ef1f3bfd4c479efd9cdd3527c473155f69b39944d98d5f738b56855e12db2fbb)

The VirusTotal report shows that the URL has been flagged as phishing by security vendors such as Fortinet, indicating that it is associated with malicious activity.  

Using URL2PNG, the webpage snapshot shows that the blog has been removed. This suggests that the page was previously active but later taken down, most likely due to being reported or identified as malicious.

Based on these findings, it is clear that the URL is malicious and part of a phishing campaign.

---

## Defensive Measure:

Since the URL and domain are clearly malicious and created for phishing purposes, they should be blocked at multiple levels such as DNS, firewall, or proxy. Blocking them will not affect business operations because they are not legitimate services.

The attachment and its hash can also be blocked using EDR solutions to prevent similar threats in the future.

Additionally, the sender domain is not related to any trusted business communication, so it can be blocked at the email gateway to reduce the chances of similar phishing emails reaching users.

---

## Conclusion

This email uses a fake delivery failure message along with a malicious Blogspot link containing financial bait. These are common phishing techniques used to trick users into clicking harmful links and interacting with malicious content.
